請用 Python 寫一個臺灣股市查詢 GUI 程式，檔案名稱為 stock.py，功能如下：

核心功能：使用者輸入股票代碼（如 2330、2330.TW、3430.TWO）或中文名稱（如 台積電、湧德），查詢後顯示：
股票中文名稱、代號、市場別（上市/上櫃/興櫃）
資料期間
最新交易日開盤價、最高價、最低價、收盤價
日線、週線(5日)、月線(20日)、季線(60日)、半年線(120日)、年線(240日) 走勢圖
圖表上標示最高價與最低價
市場資料預載：程式啟動時，在背景從以下三個官方 API 抓取所有股票代碼與中文名稱，建立查詢索引（不寫死對照表）：
上市：https://openapi.twse.com.tw/v1/opendata/t187ap03_L
上櫃：https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap03_O
興櫃：https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap03_R
用公司簡稱與全名建立名稱→代號的對照字典
日期選擇：使用者可自行輸入開始日期與結束日期（格式 YYYY-MM-DD），預設為近兩年。
GUI 使用 tkinter + matplotlib：
上方：股票輸入框 + 查詢按鈕 + 狀態列
中間：日期輸入列（開始日期、結束日期）
資訊區：顯示股票名稱、市場別、日期區間、最新交易日開高收低
圖表區：用 FigureCanvasTkAgg 嵌入 matplotlib 折線圖
技術細節：
使用 yfinance 下載股價資料，pandas 處理資料，numpy 數值運算
中文字型設為 Microsoft JhengHei
matplotlib.use('TkAgg')
查詢時用執行緒避免卡 UI
日期格式錯誤時跳出錯誤提示框
圖表標題顯示實際資料區間
程式碼風格：不要寫註解。
